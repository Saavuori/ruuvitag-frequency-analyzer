Band levels

RMS amplitude in each band over the span. Components add in power, so a band reads the total energy in it, not its loudest bin.

Power

The tag counts how long it spends in each mode; the current figures per mode are datasheet values. So the duty cycle is measured and the microamps are a model — a coin cell barely moves in voltage for months, so a voltage trend can contradict an estimate but never confirm one.

Capture health

A window containing lost samples is drawn as a gap, never filled in. Zero-filling a dropout adds a click with energy at every frequency — the artefact most easily mistaken for a real event.
